# Global Fuel Prices and Taxation Trends

A Tableau project that analyzes global fuel prices and taxation trends across countries. The dashboard compares petrol, diesel, and LPG prices and explores differences in fuel tax percentages.

## Tools Used
Tableau Public, CSV dataset, GitHub

## Dataset
`global_fuel_prices_Dataset.csv`

The dataset contains fuel price and taxation information for different countries.

## Visualizations
1. **Average Petrol Price by Country**: Compares average petrol prices across countries.
2. **Average Diesel Price by Country**: Compares average diesel prices across countries.
3. **Average LPG Price by Country**: Compares average LPG prices across countries.
4. **Average Tax Percentage by Country**: Shows differences in fuel taxation percentages across countries.
5. **Petrol vs Diesel Price Comparison**: Compares petrol and diesel prices across countries.

## Dashboard and Story
The dashboard combines the visualizations to provide a country-wise comparison of fuel prices and taxation. It includes Top 10 country views and allows users to explore the available data interactively.
